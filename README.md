# TieBa-X

TieBa-X 是一个面向 iPhone 和 iPad 的开源、非官方、无广告贴吧客户端，目标是提供纯净的浏览、搜索、互动和内容管理体验，支持 iOS 14 及更高版本。

本项目与百度公司、百度贴吧官方无隶属、授权或认可关系。“百度”“贴吧”及相关名称与标识归其各自权利人所有。发帖、回复、资料修改等能力使用非官方接口，可能受到服务端策略或风控影响，使用者需自行承担风险。

## 功能

- TiebaLite 风格首页：最近浏览、置顶贴吧、关注贴吧、列表/网格切换和一键签到
- 首页、发现、消息、我的四项主导航与推荐内容浏览
- 贴吧列表、贴吧搜索、主题帖列表与分页阅读
- 主题帖详情、楼层内容、楼中楼和作者资料查看
- 账号登录、会话保存、退出登录和会话失效处理
- 关注/取消关注贴吧与用户、点赞/取消点赞、收藏和屏蔽
- 发帖、回复、楼中楼回复、图片上传和内容提交状态管理
- 消息中心、用户资料查看与资料修改
- 图片、视频、语音内容预览及播放
- 浏览历史、搜索历史、草稿、收藏主题和本地备份
- 阅读偏好、内容过滤、表情资源、深链和 Safari 分享入口
- iPhone、iPad 以及明暗外观下的统一阅读界面

## 源码内容

- `TieBaX/`：应用主体、网络接口、领域模型、状态管理和 SwiftUI 界面
- `TieBaXOpenIn/`：Safari 分享与外部链接接收扩展
- `TieBaXCoreTests/`、`TieBaXTests/`：领域逻辑、接口契约和回归测试
- `TieBaXUITestCases/`、`TieBaXUITests/`：界面流程测试
- `Protos/`：贴吧接口使用的 Protobuf 协议源文件
- `TieBaX/Core/Protobuf/Generated/`：随源码维护的 Protobuf Swift 产物

项目名称、应用模块、扩展、测试目标和协议命名统一使用 TieBa-X / TieBaX。协议字段与兼容行为以仓库中的源码和测试为准。
